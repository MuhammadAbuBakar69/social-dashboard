# Social Dashboard Starter Code

A modern, responsive social media analytics dashboard built with React (Vite) and clean CSS.

## Features
- **Stat Cards**: Dynamic metrics for total followers, engagement rate, total posts, and reach with trend indicators.
- **CSS-Based Bar Chart**: Animated custom CSS bar chart displaying weekly activity per platform.
- **Activity Feed**: Real-time log of recent notifications, mentions, and milestones.
- **Top Posts List**: Card layout showcasing top performing content across channels.
- **Platform Filter Tabs**: Filter views by Instagram, Twitter (X), LinkedIn, or All Platforms.
- **Sidebar & Search**: Modern dark dashboard layout with sidebar navigation and search bar.

## Project Structure
- `social-dashboard_App.jsx` - Main React dashboard component.
- `social-dashboard_App.css` - Custom styling and dark theme variables.
- `social-dashboard_README.md` - Documentation.

## Getting Started
Import `social-dashboard_App.jsx` into your Vite React app:
```jsx
import SocialDashboard from './projects/social-dashboard_App';
```
